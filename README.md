# MEET & DRAW — Public Demo

**Meet someone. Draw what you see.**

MEET & DRAW is a quiet drawing-practice PWA with AI-generated portrait and figure references for artists.

Public demo: https://tarout-gif.github.io/figure-study-demo/

This repository contains only the built static demo and 100 optimized WebP references: 62 Portrait and 38 Figure images. React / TypeScript source files, generation originals, and local QA materials remain in the private development repository.

The 100-image library was published on September 26, 2026.

Built for OpenAI Build Week, July 2026.
